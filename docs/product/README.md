# Nurture product documentation

**Start here:** [Nurture product specification](nurture-product-spec.md).

## Authority and maintenance

These documents define the target product; they are **not a declaration that the features are implemented**. Read the product specification and [brand guide](../../brand/README.md) before changing application architecture. The specification records the owner's September 5, 2026 build-outline attachment and subsequent media requirements. Clarifications and implementation proposals are identified separately from that baseline.

The repository specification is authoritative for builds. Chat is a working session for proposed changes. Update the affected requirement and acceptance test in the same pull request or commit as an intentional change of product behavior. Preserve existing infrastructure and security boundaries. Record unresolved commercial or operational choices rather than silently inventing policy.
